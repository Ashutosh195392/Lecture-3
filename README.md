# Bookmark Manager (HTML)

A simple bookmark manager page built with HTML while learning web development. It groups my favorite websites into primary and secondary bookmarks, and each link opens in a new browser tab.

## Preview

The page contains:

- **Primary Bookmarks:** Google, Facebook, Quora, CodeWithHarry, YouTube
- **Secondary Bookmarks:** Wikipedia, Stack Overflow

## Project Structure

    Lecture 4/
    ├── bookmarkmanager.html
    ├── index.html
    ├── style.css
    └── script.js

## Concepts Practiced

- Basic HTML document structure
- Headings (`<h1>`, `<h2>`) to organize content
- Paragraphs (`<p>`) and anchor tags (`<a>`)
- The `href` attribute for linking to external websites
- `target="_blank"` to open links in a new tab

## How to Run

1. Download or clone this repository.
2. Open the `Lecture 4` folder.
3. Open `bookmarkmanager.html` in any browser (or use Live Server in VS Code).
